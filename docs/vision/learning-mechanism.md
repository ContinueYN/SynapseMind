# 学习机理设想：诊断—归因—干预—巩固

> 定性：**设想文档**，不是已实现产品的说明。第 7 节逐条标了「已落地 / 待做」。
> 目的：把「AI 陪我做题 + 脑神经重塑 + CHC 七维归因」这个直觉，
> 写成一个**内部自洽、能算、每一层都挂得上真实机制**的模型。
> 它不宣称测量大脑，也不宣称已获得效果数据；它宣称的是：这套东西**讲得通**，
> 而且每一环都能在没有真实学生的前提下先自证一部分。

---

## 一、核心命题

学会一道题，不是「会了 / 不会」两态，而是**一条通路被反复强化到能自动调用**。
所以把一次学习拆成四段：

```
诊断（错在哪一步） → 归因（哪个认知维度弱） → 干预（怎么教） → 巩固（何时再见）
        ↑                                                          │
        └──────────────── 通路强度 w 被更新 ←──────────────────────┘
```

四段各自对应一层真实机制：

| 层 | 用什么描述 | 挂靠的真实机制 |
|---|---|---|
| 认知层 | CHC 七维（能力分类） | 心理测量学的能力结构 |
| 神经层 | 通路强度 `w ∈ [0,1]` + 遗忘衰减 | 突触可塑性（LTP）、遗忘曲线 |
| 行为层 | 检索 / 间隔 / 示例渐隐 | 提取练习、分散练习、认知负荷 |

**关键设计**：三层不是并列的口号，而是**同一条通路的三个视角**——
认知层说「弱在哪」，神经层说「现在多强、会掉多快」，行为层说「下一步做什么动作」。

## 二、可计算的核心：通路强度

把学习单元从「一道题」下沉到「**一个步骤-技能节点**」（求导、配方、判别式、辅助线…）。
每个节点带一个强度 `w`，它决定三件事：还要不要再练、什么时候再练、练的时候给多少提示。

**更新规则**（三条，各自有出处，不是拍脑袋）：

1. **成功独立检索**（没看提示就做对）
   `w ← w + α·(1 − w)`，`α ∈ [0.2, 0.5]`
   —— 增量随当前强度递减：已经很强的通路再加也没多少空间（对应 LTP 的饱和性）。
2. **失败或看提示后做对**
   `w ← w·(1 − β)`，`β ∈ [0.3, 0.6]`
   —— 失败不是清零，是打折：能自己做一半，说明通路在，只是不稳。
3. **时间衰减**
   `w(t) ← w·exp(−Δt/τ)`
   —— 指数遗忘。`τ`（时间常数）随成功次数增长：练得越熟，掉得越慢。

**由此得到复习时刻**：当 `w` 掉到阈值 `θ`（默认 0.8）时就该再见一次，
即 `Δt* = τ·ln(w/θ)`。这不是「每天 10 题」，是**每条通路各自排期**。

这套形式与工业界的间隔重复调度器（SM-2 / FSRS / 半衰期回归）同构，
区别只在于：**我们的「记忆项」是一步技能，不是一张卡片**。

## 三、归因：从「错在哪一步」到「哪个维度弱」

### 3.1 七维工作集（键名以 `specs/` 为准）

CHC 是能力分类学，完整的 broad abilities 不止七个。取七个作为**数学诊断的工作集**。
左列是**代码键**，与 [`specs/solution-graph.schema.json`](../specs/solution-graph.schema.json)
里 `demand` 的七个字段逐字一致；中间那列是它在 CHC 里的名字。**两套写法只能有一套进代码**，
以代码为准，理论名只出现在文档里：

| 代码键 | CHC 名 | 在数学题里的样子 | 对应现有假设 |
|---|---|---|---|
| **V** | 晶体知识 `Gc` | 读不懂「恒成立」「至少存在」 | `H_L1`（语文支） |
| **Gf** | 流体推理 `Gf` | 想不到分类讨论、辅助线选错 | `H_L2` 条件转译 |
| **Gv** | 视空间 `Gv` | 看不出射影、画不出截面 | `H_L2`（几何支） |
| **WM** | 工作记忆 `Gwm` | 三步以上就丢条件、抄错行 | `H_L4` 计算 |
| **Gs** | 加工速度 `Gs` | 会但慢，考试做不完 | `H_L4`（速度支） |
| **LTS** | 长时存取 `Glr` ＋ 数量知识 `Gq` | 公式/定理想不起来，做过同型题考场想不起 | 新增 |
| **M** | 元认知（CHC 之外的因子） | 觉得自己会了，其实没有 | 新增 |

> 这张表是这套设想里最有用的一页：**它把「归因」从形容词变成了查表**。
> 现有三档假设（L1/L2/L4）是 `V`＋`Gf`＋`Gs` 这一簇的粗粒度版本，扩成七维只是把
> 词表细化，状态机一行不用改。**`Gq`（数量知识）折进 `LTS`**：在本项目里它的可观测
> 表现就是「公式记不住 / 想不起来」，与「存进去了但取不出」是同一个行为，不再单列。

### 3.2 单题只给标签，不给分数

一道题对某个维度的证据量近乎为零——这是认知诊断模型要几十道题的原因，
也是「单题测出你 Gf=72」这种说法站不住的原因。所以：

- **单题**：输出多标签 + 置信度，`{Gf: 0.6, LTS: 0.3}`，且明示「单题不足以断言」；
- **聚合**：跨题做贝叶斯更新——七维先验 `P(维度)`，每个错误节点提供一个似然
  `P(错误 | 维度)`（由节点类型 × 错误形态给出），十题之后才有画像；
- **画像的用途**：不是打分，是**决定干预方式**（见第四节）。

## 四、干预：四种动作，按 `w` 和归因选

学生写没写、写得对不对，决定了入口；归因决定了用哪种动作。

| 入口 | 归因 | 干预动作 | 对应行为机制 |
|---|---|---|---|
| 写了但有一步不成立 | `Gf`/`WM` | **指到步**：这一步的等式/式子不成立，正确形式是… | 即时纠正性反馈 |
| 写了但整段缺一步 | `LTS`/`V` | **追问**：那一步需要哪个条件？不给答案 | 提取练习 |
| 完全没写 | — | **示例渐隐**：完整示例 → 半成品 → 独立做 | 认知负荷 / 示例效应 |
| 做对了但很慢 | `Gs` | **变式 + 限时**：同型换数，压缩到目标时间 | 自动化 |
| 做对了但隔天忘 | `LTS` | **间隔重现**：按 `Δt*` 排期 | 分散练习 |

四种动作的选择规则可以写成一句话：
**`w` 低且归因在 `LTS`/`V` 就讲，`w` 中且归因在 `Gf`/`WM` 就问，`w` 高就只练不给提示。**

## 五、与生物学的对应（命名层，明确是类比）

这一段的作用是给上面那套可计算量**取名字**，不是宣称测量。每个对应都要能反向说清：
「如果这个机制不存在，我们的模型哪一条会失去依据」。

| 生物机制 | 模型里的对应 | 反向检验 |
|---|---|---|
| 长时程增强（LTP）：高频刺激后突触传递效率持久上升 | 成功检索后的增量 `α(1−w)` | 若 LTP 不存在，「练一次强一点」就没有细胞基础 |
| 突触修剪：不用的连接被删除 | 衰减项 `exp(−Δt/τ)` | 若不用的不衰减，间隔重复就没有必要 |
| 髓鞘化：反复传导后速度提升 | 「做对但慢」这条支路（`Gs`） | 若熟练不带来速度，限时训练就没意义 |
| 再巩固：提取后记忆进入可修改窗口 | 纠错时机——**先让学生自己写，再指出错** | 若提取后不可修改，纠错就只能在事前干预 |
| 神经可塑性的关键期 | 「示例渐隐」的撤脚手架节奏 | 若撤得太快，学生就退回自由解题 |

**措辞纪律**：可以说「与…一致的机制」「以…为类比」；不能说「我们激活了你的 LTP」。
前者是模型，后者是伪造测量——而伪造测量一旦被懂行的人戳破，整套设想就废了。

## 六、这个设想怎么被检验（不需要真实学生也能先自证一半）

设想的可信度不等于「有没有做过实验」，而等于**它有多少部分能被独立检验**：

| 可检验的部分 | 需不需要真实学生 | 现在能做到吗 |
|---|---|---|
| 错在哪一步（存在性） | 不需要 | ✅ 已有（对齐器） |
| 这一步的等式成不成立 | 不需要 | ✅ 已有（符号判等 + 反例） |
| 这一年级的题拆得对不对（图的结构） | 不需要 | ✅ 已有（100 题结构全过） |
| 归因是否落在正确维度 | 需要 | ⚠️ 只能先靠构造真值（缺口探针） |
| `w` 的更新是否预测了「三天后还记不记得」 | 需要 | ❌ 待做（复习卡 + 延迟正确率） |

**这张表就是这份设想最硬的地方**：前四行现在就能拿证据，第五行是它唯一还没落地的断言，
所以它被明确标成「待验证」，而不是含糊过去。

## 八、边界

1. 这是**模型**，不是测量。`w` 是我们对「通路强度」的代理量，不是神经活动的读数。
2. CHC 七维是**标签空间**，不是分数仪器；单题只给标签与置信度。
3. 生物机制是**命名与类比**，用来约束模型形状（衰减、饱和、可修改窗口），不是宣称因果。
4. 唯一能证明「学会了」的指标是**延迟正确率**——在它出现之前，
   这套设想只有前半段有证据，后半段是设计。
5. 不写没有出处的百分比，不配脑成像图：这两样是设想变成营销话术后**最先崩的地方**。
