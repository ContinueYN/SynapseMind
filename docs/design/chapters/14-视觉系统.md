# 14. 视觉系统：琉璃

> 本章是界面层的唯一真源。任何颜色、字号、间距、圆角、动效，若与本章冲突，以本章为准。
> 与第 2 章 §2.7 的关系：**§2.7 的"说人话"约束优先于任何视觉表达**（见 §14.9 术语分层）。
> 实现：`apps/web/app/styles/tokens.css` + `apps/web/app/styles/glass.css`。

## 14.1 出发点

界面要像一块**冰蓝的玻璃**，而不是一个 SaaS 落地页。

- 一色一族：冰蓝 → 雾白 → 纯白，只有明度差别，没有第二种颜色
- 质感来自**光学**，不来自贴图：光、折射、色散、壁厚
- 交互必须承载产品语义：液面高度 = 走过的轮次；选项果冻 = 你正在选的那一行

判断标准只有一条：**把阴影和模糊全关掉，版面还立不立得住。**

## 14.3 字体


全站一套无衬线。**没有衬线、没有等宽、没有装饰体**（衬线方案已于 H4 明确否决）。

### 字距按光学尺寸分别定（这条最容易做错）

| 字号 | letter-spacing | 用途 |
|---|---|---|
| 62px | `-.029em` | 首页标题 |
| 32px | `-.023em` | 卡点结论 |
| 25px | `-.017em` | 面板标题 |

## 14.4 一块玻璃 = 五层光学 + 一层内容

层序写死在 `glass.css` 里，新组件不要再自己叠 z-index：

| z | 层 | 作用 |
|---|---|---|
| 0 | `.sm-lens` | **折射**：读背景光斑的真实坐标，换算成局部百分比，按指针反向偏移 |
| 1 | `.sm-spec` / `.sm-streak` / `.sm-frost` | 镜面高光 / 斜向光带 / 内壁磨砂 |
| 2 | `.sm-chroma` | **色散**：边缘冷青 + 暖粉各 1.5px |
| 3 | `::before` | 高光边：上缘纯白 → 中段冷蓝 → 下缘再亮 |
| 4 | `.sm-glass-in` | 内容 |

硬规则：

1. 折射层必须读**真实**光斑坐标（`GlassCard.tsx` 的 `syncRefraction`），不许用固定渐变糊弄
2. 高光跟着指针走（`--mx/--my`），不许钉在中间
3. 圆角只有三档：`26px` 大块、`18px` 中块、`14px` 输入框；胶囊用 `99px`
4. 阴影只有一套：`0 28px 68px -32px rgba(34,86,120,.48)` + `0 6px 18px -10px`

## 14.6 液面：唯一的数据可视化

液面高度 = `turn / max_turns`，弹簧式上升，**最后一轮之前不会到顶**。

人话解释：水没满 = 还没定位到。这不是装饰，是把"诊断走完没有"画出来。

物理三条：

| 行为 | 实现 |
|---|---|
| 推容器 | 液面倾斜，倾角 ∝ 横向速度，松手按 0.9 阻尼平复 |
| 点水面 | 涟漪从**落点**扩散（高斯 × 正弦），不是从中间冒泡 |
| 答一轮 | 液面升一格 + 涟漪 + 卡面扫过一道高光 |

右侧刻度数 = `max_turns`，走过几轮亮几格。刻度不写死，跟后端轮次上限走。

## 14.8 能力构成表：**当前不上线**

主题"智商核心构成能力"唯一合法的界面形态，是「**这道题需要什么**」＋「**你的证据**」，而不是「你有什么」的分数。

三态定义（等数据到位再启用）：

| 状态 | 标记 | 含义 |
|---|---|---|
| 有证据 | 实心点 | 这一步你写对了，证据完整 |
| 缺一步 | 空心点（`--blue-700`） | 有动作缺失，能指出缺哪一步 |
| 未涉及 | 虚框点 | 这题走不到这一步，不给结论 |

**现状**：后端 `CardOut` 未暴露解法图节点，前端**没有**这张表。不许用假数据填，宁可空着。

硬规则不变：

1. 不产出分数、百分位、雷达图、等级
2. 三态只能由节点数据驱动，前端不得硬编码
3. 标题用「这道题需要什么」，不用「你的能力」

## 14.9 术语分层（对 §2.7 的落地）

| 层 | 默认可见 | 内容 |
|---|---|---|
| 第一层（人话） | ✅ | "先确认前提，再动手" |
| 第二层（术语） | ❌ 悬停或展开 | "inhibitory control · 在动作启动前抑制它" |

界面任何位置不得直接把"工作记忆""抑制控制"当标签摆出来。第二层必须同时给出**人话 + 英文术语 + 一句解释**。

## 14.10 动效

| 位置 | 做什么 | 参数 |
|---|---|---|
| 液面 | 持续正弦波动 | 每帧重写路径，振幅 2.1 |
| 选项果冻 | 滑到光标行 | `.66s` + `cubic-bezier(.3,1.35,.4,1)` 过冲 |
| 卡片倾斜 | 指针驱动，带惯性 | lerp 0.09，最大 8° / 6° |
| 答完闪光 | 高光扫过整块玻璃 | `.95s` |
| 按钮水波 | 点击位置散开 | `.7s` |
| 背景视差 | 光斑反向缓动 | lerp 0.04 |

`prefers-reduced-motion: reduce` → 三层光学（折射 / 高光 / 光带）直接 `display:none`，动画时长降到 0.01ms。

## 14.11 无障碍

- 正文对比度 `--ink` on `--ice-050` ≈ 13:1
- 状态不只靠颜色：选中同时有实心圆点 + 果冻位移
- 焦点环：`outline: 2px solid rgba(78,147,190,.6)`，offset 3px
- 键盘：`1–9` 直接作答；选项、返回、退出均可 Tab 到达
- 移动端：左栏液面转横向排布，`sm-cols` / `sm-act3` 单列重排
- 液面 `role="img"` + `aria-label`（"诊断进度：第 n 轮，共 m 轮"）

## 14.12 反模式（出现即打回）

1. 紫蓝渐变的"AI 感"玻璃（本设计是冰蓝一族，不是紫）
2. 装饰性英文小标题（`TRACE` `INSIGHT` 之类）
3. 大写字母 + 超大字距当标签（`L E T T E R S P A C E D`）
4. 描边空心编号 01 / 02 / 03 当装饰
5. 对偶金句、三个连续的"不是 X"
6. 给能力打分数或排名
7. 动效超过 1s，或一排元素依次入场
8. 用贴图 / 噪点冒充质感（质感在光学里，不在纹理里）
9. 玻璃上再叠玻璃（一屏最多 4 块，多了就糊）
