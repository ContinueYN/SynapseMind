# 13. 视觉系统：琉璃 · 浅蓝 · 液态白

> 本章是界面层的唯一真源。任何颜色、圆角、模糊、动效，若与本章冲突，以本章为准。
> 与第 2 章 §2.7 的关系：**§2.7 的"说人话"约束优先于任何视觉表达**（见 §13.10 术语分层）。
> 实现：`apps/web/app/styles/tokens.css` + `apps/web/app/styles/surface.css`；组件在 `apps/web/components/`。

> 版本说明：本章第 5 版（**层次**）。前四版分别是"冰蓝玻璃""纸 · 墨 · 批注""深蓝底 + 白玻璃""一整条流"。
> 第 4 版被推翻，因为实测截图证明了三件事：**玻璃压在白底上等于没有玻璃**（板内 `#f7fbff`、板外 `#f5f9fe`，差 2 个色阶）、
> **正文直接落在渐变上**（没有"面"，页面是平的）、**动效太快太硬**（≤400ms 的位移看起来像抽动而不是流动）。
> 本版只做三件事：**把玻璃做成有四层的材质**、**给页面加景深与惯性**、**让每一段文字都坐到玻璃上**。

## 13.1 出发点

这个产品是**把一道题放在光下拆开看**。光在下面，玻璃浮在光里，字坐在玻璃上——三层缺一层，页面就塌成一张壁纸。

- **四层材质，不是"玻璃 + 背景"两层**：`ground`（地）→ `plane`（段落的玻璃板）→ `tile`（板上的玻璃砖）→ `chip`（砖上的玻璃键）。**每往上一层更白、更亮、更薄、抬得更高**；往下则是"嵌进去"的更暗的槽。层次不是靠色带，是靠这四层的物理差。
- **玻璃必须是浅蓝的**：白玻璃 + 白底 = 看不见。板子的**身体**是浅蓝（`#C4DCFA` 一带），白只留作**高光**——上缘 1px 纯白边、表面一团跟手的白光、指针处一小片镜面。实测：板内比板外蓝 21–24（`b−r`），暗 14–26 个亮度级。
- **每段字都必须有"面"**：正文不许直接压在 `.sm-bg` 上。一个 `<Plane>` 包住"页签 + 一句话 + 内容"，板内留白 56/40px，页签从板的上缘**探出去 20px**（`translateY(-54%)`）——这是"这张纸是放上去的"的人证。
- **错落，不对齐**：四段板的宽度是 1088 / 900 / 960 / 840，第二段右靠（`margin-left:auto`），最后一段居中。**整整齐齐四块等宽板 = 卡片阵列 = 打回**。
- **动效要慢，还要有惯性**：跟手光不直接写坐标，每帧只走剩余的 18%（指数逼近），所以指针停下后光还会再滑一小段；入场不是"闪出来"，是 `opacity + translate + blur(5px)` 三件事一起用 760–820ms 铺开，子项错开 80–100ms。
- **景深是真的**：滚动的整数像素写进 `--scroll`，地板层用 `translate: 0 calc(var(--scroll)*Npx)` 各自不同速（0.02 / 0.03 / 0.05 / 0.085 / −0.06）跟着走——**近的板不动，远的光挪**，页面才有厚度。
- **可读性优先于质感**：正文永远是 `--ink` 实色；所有光层都在文字**下面**（`::after` 光层 `z-index:-1`，内容 `z-index:1`）。
- **追问时题目必须在场**（§13.8 `ProblemBrief`）；**任何一屏都能一步回首页**（§13.8 `TopBar`）。

五条判断标准，任一条不成立就打回：

1. **眯眼看**：能不能一眼数出哪几块是浮起来的。数不出 = 层次没做出来。
2. **关掉所有光和动画**：靠边缘、内壁、阴影，层次还立不立得住。
3. **取样**：板内 `b−r` 至少比板外 `b−r` 大 8；板内亮度至少比板外低 8。（白板 + 白底 = 打回）
4. **正文四周 12px 内必须有玻璃**：文字直接压底的段落，一律补 `<Plane>`。
5. 它像一份排过的版面，还是像把几个组件摆进格子。

## 13.2 关键词

浅蓝、近白、透、薄、慢、有厚度、有惯性、有刻度。反义词写在 §13.13。

## 13.4 四层材质与玻璃配方

### 四层

| 层 | 类名 | 圆角 | 抬升 | 模糊 | 用途 |
|---|---|---|---|---|---|
| `ground` | `.sm-bg` + 光斑 | — | — | — | 地板：渐变 + 五层游光 |
| `plane` | `.sm-plane` | `--r-4` 30px | `--lift-plane`（三层） | **无**（性能） | 一个段落的玻璃板：页签 + 一句话 + 内容 |
| `sheet` | `.sm-sheet` / `.sm-probe` | `--r-4` 30px | `--lift-sheet`（四层） | `blur(26px) saturate(170%)` | 唯一"贴着现实"的大玻璃：交题板、追问卡 |
| `tile` | `.sm-tile` | `--r-3` 22px | `--lift-tile`（两层） | 无 | 板上的玻璃砖：步骤、笔记、对话行 |
| `chip` | `.sm-chip` | `--r-2` 14px / `--r-pill` | `--lift-chip` | 无 | 砖上的键：页签、选项、标签 |

**往上更白**：`--glass-plane`（浅蓝身体）→ `--glass-sheet`（更白、更亮）→ `--glass-tile`（白到近乎纸）→ `--glass-chip`（最白）。
**往下是嵌进去的槽**：输入格、索引板、答案条用 `inset` 阴影而不是落影——凹陷与抬升是两种反方向的层次，缺一种页面就又平了。

### 玻璃配方

```css
/* 1. 身体：先一层蓝底，再叠渐变。只给渐变，板子会在白底上消失。 */
background-color: var(--glass-tint);          /* rgba(150,192,240,.12) */
background-image: var(--glass-plane);         /* 白 → 浅蓝，三层停靠点 */

/* 2. 边：上缘纯白（光从上面来），下缘冷蓝（折射） */
border: 1px solid var(--glass-edge);
border-bottom-color: var(--glass-edge-cool);

/* 3. 落影三层：贴边 1px + 中景 + 远景。阴影是**蓝的**，不是灰的 */
box-shadow:
  var(--lift-plane),
  var(--glass-rim),        /* inset 0 1px 0 #fff */
  var(--glass-rim-lo),     /* inset 0 -1px 0 rgba(108,158,222,.46) */
  var(--glass-wall);       /* 内壁：上 16px 白光 + 下 26px 蓝 + 内描边 */
```

```css
/* 4. 边缘冷光：::before 铺满、padding 1px、双层 mask 只留 1px 的边 */
.sm-plane::before,
.sm-sheet::before { background: radial-gradient(320px 320px at var(--mx) var(--my), …); }

/* 5. 表面柔光 + 颗粒：::after 在 z-index:-1，绝不在文字上面 */
.sm-plane::after  { background: radial-gradient(380px 320px at var(--lx) var(--ly), rgba(255,255,255,.78), transparent); }

/* 6. 玻璃里的光（"液态"主件）：三团白光各走各的 */
.sm-sheen            { animation: sm-sheen-drift   32s ease-in-out infinite alternate; }
.sm-sheen::before    { animation: sm-sheen-drift-b 46s ease-in-out infinite alternate; }
.sm-sheen::after     { animation: sm-sheen-drift-c 58s ease-in-out infinite alternate; }

/* 7. 液面斜扫：一道很淡的斜光，26s 走一趟，只在 clip 里 */
.sm-glass-clip::after { animation: sm-streak 26s var(--ease-out) infinite; }
```

**z 序是硬约束**（写反了字就被光糊掉）：

| 层 | z-index |
|---|---|
| 玻璃的落影 / 表面柔光 `::after` | `-1` |
| 玻璃里的光 `.sm-sheen` | `0` |
| 内容 `.sm-plane-in` / `.sm-sheet-in` | `1` |
| 边缘冷光 `::before`、页签 | `3–4` |

其他硬约束：

- `--mx/--my`、`--lx/--ly`、`--rx/--ry` **只能由指针事件写 style 变量**，不许进 React state；统一走 `components/useGlass.ts`，触屏与 reduce-motion 不启用。
- **跟手是阻尼的**：每帧只补剩余距离的 18%（`lerp 0.18`），差 < 0.0008 时吸附停帧。所以 CSS 里**不许给 `transform` 加 transition**——惯性在 JS 里，CSS 再过渡一次就会抖。
- **只有 `sheet` 倾斜**（±1.5° / ±1.05°，`perspective(1600px)`）；`plane` 不倾——页面级的大面积倾斜会晕。
- `backdrop-filter` 全站**最多 4 处**：`.sm-top`、`.sm-sheet`、`.sm-probe`、`.sm-brief`。`plane`/`tile` 一律不用（滚动时会掉帧）。
- `saturate()` 不超过 180%：再高整块板子发紫。

## 13.5 字体

```css
--sans: -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB",
        "Microsoft YaHei", system-ui, sans-serif;
```

全站一套无衬线，不引外部字体（本机直连外网不通，`next/font/google` 会卡死构建）。

"高级感"来自**字重、字距、字号三者的对照**，不来自换字体：

| Token | 值 | 用途 |
|---|---|---|
| `--fs-display` | `clamp(38px,4.8vw,68px)` | 首页字标（600，`-.044em`，行高 `1.02`） |
| `--fs-h1` | `clamp(27px,3.1vw,40px)` | 状态页主结论 |
| `--fs-h2` | `clamp(19px,2vw,25px)` | 卡点一句话 |
| `--fs-q` | `clamp(19px,1.9vw,23px)` | 追问句（500） |
| `--fs-lead` | `17.5px` | 导语 |
| `--fs-body` | `15.5px` | 正文 |
| `--fs-p` | `14.5px` | 次级正文 |
| `--fs-small` | `13px` | 注脚、按钮 |
| `--fs-meta` | `12px` | 元信息 |
| `--fs-tag` | `11px` | 小标签（必须 `--azure-ink`） |

标题是一个**字标**，不是一句话：第一行 `.sm-display`（68px/600），第二行 `.sm-display-2`（`0.64em`、`--ink-2`、500）。两行之间的比例差就是"排版"。

全站 `font-variant-numeric: tabular-nums`；标题里要强调的词用 `.sm-hl`（一笔浅蓝液体高光），**不用渐变字**。

## 13.6 栅格与流动

- 版心 `--measure: 1160px`，左右 padding 36px；正文列 `--measure-read: 33em`
- 首页主区：`minmax(0,1fr) + 418px`，间距 44px；**交题板比字标低 40px**（错位，不要对齐得像模板）；≤1080px 变单列，板子限宽 540px
- 追问页：左轨 250px ＋ 40px ＋ 舞台（`max-width: 760px`）；左轨是**一块粘性玻璃板**（`top: 92px`），舞台是**一整块玻璃台面**；≤1080px 左轨变横向一条
- 间距：`--s1 4 / --s2 8 / --s3 14 / --s4 20 / --s5 28 / --s6 40 / --s7 56 / --s8 80 / --s9 104 / --s10 136`
- 圆角只有 `10 / 14 / 22 / 30 / 999` 五档；**文字块本身不要圆角，圆角只给玻璃**
- 页面是**一串错落的板**，只有七种段落形态，不要发明第八种：

| 形态 | 类名 | 长什么样 |
|---|---|---|
| 字标 | `.sm-display` + `.sm-display-2` | 两行、一大一小、左对齐 |
| 页签 | `.sm-label` | 玻璃小签，压在板上缘外面 20px；`01` 序号 + 11px 字 + 一条 18px 液面 |
| 一句话 | `.sm-statement` | 21–29px，**每段的层级就靠它** |
| 液态轨道 | `.sm-track` / `.sm-step` | 4 块玻璃砖 + 一条 2px 液面轨道，7.4s 一趟流光；悬停哪段填哪段 |
| 索引 | `.sm-index` | `字段名 ···· 它回答什么`，嵌进板里的凹板，悬停引线变亮、右端推 2px |
| 悬挂标签 | `.sm-note-item` | 左 7.5em 标签 + 右正文，每一条是一块玻璃砖 |
| 示例卡 | `.sm-cardmock` | **全站唯一一张"纸"**：白底、`rotate(-0.55deg)`、指针压上去自己摆正。示例卡用它，不许再用一堆文字描述卡长什么样 |
| 引文 | `.sm-quote` | 左 2px 蓝条 + 26–38px 大字，单独一块居中的板（首页目前不用，留作结尾备用） |

- **板宽要变**：`1088`（默认）/ `.sm-flow--right` 900（右靠）/ `.sm-flow--narrow` 960 / `.sm-flow--center` 840（居中）。等宽四块 = 卡片阵列 = 打回。
- 段落之间留白 `--s8 / --s9`（80–104px）。**允许**页签、玻璃砖、玻璃板；**不允许**分割线、色带、等宽等高的卡片阵列。
- 段落入场由 `Reveal` 控制：进入视口的那一段 `opacity 0→1 + translate 28px→0 + blur 5px→0`，760ms；子项（页签/一句话/砖）按 80–100ms 错位，820ms 上浮 16px。**读过的不再动**。
- 换屏（`app/template.tsx`）也是 `opacity + translate + blur`，620ms，不是硬切。

## 13.7 树突：唯一的数据可视化

树突 = 走过的路。**用节点数画，不用像素画。**

- 首页四格：题目 / 答案 / 过程 / 卡点。填了哪格亮哪格；光标停在某个字段，那一格也跟着亮。
- 追问页：每答一轮加一颗玻璃珠（`第 n 问` + 你原话的摘要）；指针停在某一行问答上，左轨对应的珠子亮起来；出卡时末端变成"卡点"节点。
- 说"不知道"的那一轮，枝干**向左让一步**——路径退回一级。

几何由序号算出，没有随机数（`Dendrite.tsx`，`step` 默认 58 / 追问页 46，脊线 `x=24`）。

| 状态 | 线 | 珠 |
|---|---|---|
| `done` | `--azure-line` | 实心蓝珠 |
| `active` | `--azure` 1.5px | 白珠 + 蓝边 + 3.2s 呼吸圈 + 6px 辉光 |
| `todo` | `--line-2` 虚线 | 半透明白珠 |
| `stuck` | `--azure-ink` 1.5px | 深蓝珠 + 三道短须 |

硬约束：

1. 节点数只能来自真实数据（`history.length` / 草稿字段），**不许预先画满**
2. 树突是 `<svg aria-hidden>` + 一份 HTML 文字标签（`ol.sm-d-labels`），读屏读到的是句子
3. `data-hot` 只是联动提示，不改变状态

| 17 | **进度柱** | `Dendrite.tsx` | 一根玻璃管 + 液面 + 几颗珠。**不许再画折线、曲线、短须**（22px 宽里第三样东西就开始糊） |
| 18 | 指针场 | `PointerField.tsx` | 指针位置写进 `--gx/--gy`（−1…1），背景六层光各乘不同系数，每帧补 12% |
| 19 | 会翘的砖 | `useTilt.ts` | 事件委托：指针在 `[data-tilt]` 上时写 `--mx/--my/--rx/--ry`；只给砖，不给文字块与按钮 |
| 20 | 换页 | `Transit.tsx` + `app/template.tsx` | 一层水从顶上淌下去（660ms），新页在它下面上浮淡入。**必须挂在 `.sm-page` 外面**——那一层有 `translate` 与 `blur`，会变成 fixed 子元素的包含块 |

## 13.9 能力构成表：**当前不上线**

主题"智商核心构成能力"唯一合法的界面形态，是「**这道题需要什么**」＋「**你的证据**」，而不是「你有什么」的分数。

三态（等数据到位再启用）：

| 状态 | 标记 | 含义 |
|---|---|---|
| 有证据 | 实心蓝珠 | 这一步你写对了，证据完整 |
| 缺一步 | 空心蓝珠 | 有动作缺失，能指出缺哪一步 |
| 未涉及 | 虚框珠 | 这题走不到这一步，不给结论 |

**现状**：后端 `CardOut` 只给 `layer / node_id / label`，不给节点全集，前端**没有**这张表。不许用假数据填，宁可空着。

1. 不产出分数、百分位、雷达图、等级
2. 三态只能由节点数据驱动，前端不得硬编码
3. 标题用「这道题需要什么」，不用「你的能力」

## 13.10 术语分层（对 §2.7 的落地）

| 层 | 默认可见 | 内容 |
|---|---|---|
| 第一层（人话） | ✅ | "先确认前提，再动手" |
| 第二层（术语） | ❌ 悬停或展开 | "inhibitory control · 在动作启动前抑制它" |

界面任何位置不得直接把"工作记忆""抑制控制"当标签摆出来。第二层必须同时给出**人话 + 英文术语 + 一句解释**。

## 13.11 动效

**动效只做三件事**：跟手（光与倾斜）、交代变化（换屏 / 换问 / 入场）、造景深（滚动视差与慢光）。
时长全部走 token，**没有硬切、没有回弹**（唯一带一点点过冲的是 `--ease-liquid`，只给液面用）。

| Token | 值 | 用途 |
|---|---|---|
| `--t-fast` | `160ms` | 键帽、下划线、箭头 |
| `--t-base` | `240ms` | 悬停、聚焦、推 2px |
| `--t-slow` | `360ms` | 砖入场、行入场 |
| `--t-liquid` | `620ms` | 液面填充、光斑抬升 |
| `--t-rise` | `780ms` | 整段上浮淡入 |
| `--t-page` | `620ms` | 换屏 |
| `--ease-glide` | `cubic-bezier(.2,.78,.24,1)` | 默认：快出慢收，像被水推着停 |
| `--ease-liquid` | `cubic-bezier(.3,.9,.28,1.04)` | 液面 |
| `--ease-out` / `--ease-draw` | `cubic-bezier(.22,.72,.28,1)` / `(.22,.61,.36,1)` | 淡出 / 画出 |

| 位置 | 做什么 | 参数 |
|---|---|---|
| 换屏 | 一层水从顶上淌下（`translateY(101%)`），前缘一道白线 + 斜光；新页在下面上浮 14px + 淡入 + `blur(4px)→0` | 660ms / 780ms |
| 进度柱 | 液面高度（走过的部分被蓝填满） | `--t-liquid` 620ms |
| 指针场 | 背景六层光按 `--gx/--gy` 各自漂 6–36px，每帧补 12% | 实时 |
| 玻璃砖 | 朝指针倾 ±1.2°/±0.9°，白光跟手，阴影加深 | 320ms |
| 示例卡 | 指针压上去，纸从 −0.55° 摆正 | 560ms |
| 段落入场 | 整段上浮 28px + 淡入 + `blur(5px)→0`；子项各错 80–100ms，各上浮 16px | 760 / 820ms |
| 对话行入场 | 上浮 10px + 缩到 0.99 + 淡入，每行错 80ms | `--t-slow` 360ms |
| 玻璃里的光 | 三团白光各自漂移 | 32 / 46 / 58s 交替 |
| 液面斜扫 | 一道淡斜光划过玻璃 | 26s 循环 |
| 水光 | 三团浅色缓移 | 38s 交替 |
| 整页游光 | 一团淡蓝光绕一圈 | 120s 线性 |
| 三团光斑 | 各自呼吸漂移 | 96 / 124 / 150s 交替 |
| 雾 / 地光 | 一层雾上浮、一层地光呼吸 | 52s / 24s 交替 |
| 板下光滩 | 呼吸（缩放 + 透明度） | 18s 交替 |
| 轨道流光 | 一趟扫过管道（管道内裁切） | 7.4s 循环 |
| 标签圆点 | 呼吸 | 4.6s 循环 |
| 指针进玻璃 | 边框冷光 + 表面柔光跟位（阻尼 18%/帧） | 跟随实时 |
| 指针进大玻璃 | 倾 ±1.5° / ±1.05°，离开吸附回位 | 跟随实时 / JS 阻尼 |
| 输入聚焦 | 整格亮 + 3px 蓝晕 + 底部 1px 液线从左画出 | 300ms 画出 |
| 线索液面 | 宽度走位 + 一次亮度抬升 | 620 / 460ms |
| 悬停一块砖 | 抬 1px + 阴影加深 + 边框冷光 | `--t-base` 240ms |
| 按钮 | 悬停时里面那团光跟着指针；按下压 1px + 内阴影；箭头右移 3px | 160–240ms |
| 顶部液面 | 宽度随滚动 | 90ms |

**景深**（`--scroll` 由 `ScrollRule` 写成整数像素，`translate` 与 `transform` 分开用，互不覆盖）：

| 层 | 系数 |
|---|---|
| 水光 `.sm-bg::after` | `0.05` |
| 游光 `.sm-bg::before` | `0.02` |
| 光斑 1 / 2 / 3 | `0.03` / `−0.06` / `0.085` |
| 雾 / 地光 | `0.09` / `−0.02` |

**禁止**：水珠、扫光条、文字块位移/缩放、文字逐字入场、对文字做模糊或发光、超过三层的落影、`transform` 上再加 CSS transition、光斑盖住正文。

**允许但仅限"键"**（选项、按钮、键帽）：1px 的抬升/压回。这是物理反馈，不是装饰。

`prefers-reduced-motion: reduce` → 全部动画降到 0.01ms；视差、跟手光、倾斜全部关闭；`[data-in="false"]` 强制可见。**信息一条都不能丢。**

## 13.12 无障碍与性能

- 正文对比度：`--ink` on `#E9F3FE` ≈ 14:1；`--ink-3` 标签 ≈ 5.2:1；蓝底白字按钮 ≥ 4.5:1
- **11px 及以下小字只能用 `--azure-ink`**（`--azure` 在白底上不够）
- **整页禁止选中**（`user-select: none`），`input / textarea / [contenteditable]` 显式恢复 `text`
- 状态不只靠颜色：选中同时有左条 + 勾；当前节点同时有呼吸圈 + 文案
- 焦点环：`2px solid var(--azure-line)`，offset 3px
- 键盘：`1–4` 作答，`H` 看"为什么问这个"，Tab 可达所有控件
- 触屏：不接指针相关效果；选项 ≥ 44px 高；题面不吸附
- 性能预算：`backdrop-filter` 最多 4 处；所有慢光只动 `transform`；颗粒是 SVG 底图，不用 canvas；滚动的视差写在 `translate` 上（合成层，不触发重排）

## 13.13 反模式（出现即打回）

1. 深色玻璃 / 霓虹描边 / 紫粉渐变
2. **把底色压深**（比 `#CFE2FA` 更深）：整页发闷，玻璃反而看不出来
3. **白玻璃压在白底上**：板内与板外差不到 8 个色阶，等于没有玻璃
4. **正文直接压在底上**：任何一段话，四周 12px 内必须有玻璃
5. **四块等宽等高的板**：这是卡片阵列，不是版面；板宽必须错落
6. **等宽等高卡片 + 每块都带标题栏**的仪表盘造型
7. 按下水珠、按钮扫光条、文字块悬停位移/缩放
8. 文字逐字入场、对文字做模糊/发光/渐变填充
9. 玻璃叠玻璃超过四层，或同一屏出现两块 `sheet`（`backdrop-filter` 叠两层就糊）
10. 光斑超过五层，或光层盖住正文（`z-index` 写反）
11. 面板倾斜超过 1.5°，或给文字块、列表、按钮加倾斜（会晕）
12. 装饰性英文小标题（`TRACE` `INSIGHT` 这类）
13. 对偶金句、三个连续的"不是 X"
14. 给能力打分数或排名
15. 追问页看不见题面、或回首页要点两次
16. 11px 小字用 `--azure`（对比度不够，必须 `--azure-ink`）
17. `transform` 上再写 CSS transition（和 JS 阻尼打架，会抖）
18. **给"砖"以外的东西加倾斜**：文字块、列表、按钮一倾就晕
19. **把换页那层水放进 `.sm-page`**：那一层有 `translate` 与 `blur`，fixed 会按整页高度铺
20. **进度柱上画曲线、折线、"卡点"短须**：22px 宽只放得下一根管和几颗珠

## 13.14 落地顺序

1. `tokens.css`：近白底、琉璃色、四层玻璃参数、三层抬升、字阶、间距、动效曲线（旧变量名保留为别名）
2. `surface.css`：`.sm-bg` 六层光、四层材质（共用一个玻璃基底）、`::before` 冷光、`::after` 柔光 + 颗粒、`.sm-sheen` 三层慢光、`.sm-glass-clip` 斜扫、页签、轨道、索引、引文
3. 先做 `Ground` / `Plane` / `Surface` / `useGlass` / `ScrollRule`，再做三屏：交题 → 追问 → 定位；`app/template.tsx` 负责换屏
4. 每移植一个组件，删一处旧样式；`GlassCard` / `Backdrop` / `glass.css` 是本版的前身，不要恢复旧文件
## 13.15 文案（这一节和第 13.3 一样硬）

界面上每个字都是产品的一部分。上一版被指出"AI 味重"，问题不在措辞好不好听，而在**句式**：

| 不许 | 改成 | 为什么 |
|---|---|---|
| 对偶、格言：「只给位置，不给答案」「一张纸，四个字段，没有分数」 | 「它只做一件事：定位。」 | 金句是总结陈词的口气，产品不该替用户总结 |
| 三个连续的"不是 X" | 直接说这次给什么 | 排比是为了气势，不是为了说清 |
| `·` 连接一切（「单题诊断 · 学习模式」「突触智学 · 单题诊断」） | 只留一个词：`单题诊断` / `高中数学 · 函数与导数` | `·` 是装饰性的分隔符，用多了像模板 |
| 破折号补一句感慨：「停下就行——那个位置比答案有用」 | 「停在哪一行，第一问就从哪一行开始。」 | 后半句要是信息，不能是修辞 |
| 「原则」「哲学」「洞察」这类大词 | 换成动作和数量：一轮 6–8 分钟、2–6 轮、四个字段 | 具体的数字比形容词可信 |
| 同一件事说三遍（"不给答案"在首页出现 3 次） | 说一次，其余地方给别的信息 | 重复＝没有更多可说 |

另外两条：

1. **示例代替描述**：卡点卡长什么样，就直接放一张示例卡（`.sm-cardmock`），不要用三句话形容它。
2. **限度要写在最前面**：只支持一道题，就写在页脚与表单下面，不藏在角落。
