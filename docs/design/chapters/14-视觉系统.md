# 14. 视觉系统：琉璃 · 浅蓝 · 液态白

> 本章是界面层的唯一真源。任何颜色、圆角、模糊、动效，若与本章冲突，以本章为准。
> 与第 2 章 §2.7 的关系：**§2.7 的"说人话"约束优先于任何视觉表达**（见 §14.10 术语分层）。
> 实现：`apps/web/app/styles/tokens.css` + `apps/web/app/styles/surface.css`；组件在 `apps/web/components/`。

> 版本说明：本章第 4 版。第 1 版"冰蓝玻璃"、第 2 版"纸 · 墨 · 批注"、第 3 版"深蓝底 + 白玻璃"均已被本版取代。
> 本版改了三件事：**底色回到近白**（第 3 版压得太深）、**玻璃改成淡蓝的板子**（白玻璃在白底上是不存在的）、
> **版面从"色带分区"改成"一整条流"**（第 3 版的色带与分栏线把页面切碎了）。

## 14.1 出发点

这个产品是**把一道题放在光下拆开看**。所以：页面是一池几乎白的光，蓝从低处和角落里渗出来；面板是一块淡蓝的玻璃，浮在光里。

- **底色几乎白**：`#FFFFFF → #DCEAFB`（最深处只到 `#DCEAFB`）。**压深是错的**——第 3 版把底压到 `#C3D8F3`，整页发闷。
- **玻璃是一块淡蓝的板子**：白玻璃放在白底上等于没有玻璃。板子要比页面**更蓝**（不是更白），白高光才有东西可反。
- **液态 = 光在动 + 玻璃在弯**：①板子里有三团速度不同的白光在慢慢走（32s / 46s / 58s）；②指针在板上时，柔光跟手，板子同时倾 1–1.5 度（`perspective(1500px)`）；③整页有一团很淡的蓝光在 120s 里绕一圈；④板子底下那滩光 16s 呼吸一次。不做水珠、不做扫光条、不做漂浮。
- **层次靠"一句话 + 序号"**：每一段是 `小标签(01/02/03) → 一句话(21–29px) → 内容`。**只有一句话是层级**，标签和正文都做它的陪衬——上一版所有字都在 13–15px，所以看着单调。
- **一整条流，不切块**：段落之间只有留白、一个 11px 的小标签、一条会跟着悬停填满的液面轨道。**没有色带、没有分栏细线、没有卡片阵列**（第 3 版正是这些让它像被切碎了）。
- **可读性优先于质感**：正文永远是 `--ink` 实色；所有光层都在文字**下面**（`z-index: 0`，内容 `z-index: 1`）。
- **追问时题目必须在场**（§14.8 `ProblemBrief`）；**任何一屏都能一步回首页**（§14.8 `TopBar`）。

五条判断标准，任一条不成立就打回：

1. 把背景模糊关掉，版面还立不立得住。
2. 把三团光斑挪走，字还读不读得清。
3. 关掉所有动效，信息还读不读得出。
4. 在交题板旁边取样，背景必须落在 `#F7FBFF`–`#DCEAFB` 之间；**比 `#EEF5FD` 更白就是白板，比 `#D3E4F9` 更深就是发闷**。
5. 它像一份排过的版面，还是像把几个组件摆进格子。

## 14.4 玻璃配方

```css
/* 一块淡蓝的板子 */
border: 1px solid rgba(255, 255, 255, .98);
border-bottom-color: rgba(154, 190, 235, .55);  /* 下缘偏冷：光从上面来 */
border-radius: 22px;
background: linear-gradient(146deg,
  rgba(255,255,255,.72) 0%,
  rgba(212,233,255,.60) 44%,
  rgba(162,200,246,.74) 100%);
backdrop-filter: blur(24px) saturate(160%) brightness(1.02);
box-shadow:
  0 30px 60px -34px rgba(46,92,158,.38),   /* 落影：让玻璃离开背景 */
  0 16px 34px -28px rgba(74,140,224,.45),
  0 1px 2px rgba(31,63,107,.08),
  inset 0 1px 0 rgba(255,255,255,1),        /* 上缘高光 */
  inset 0 -1px 0 rgba(126,172,226,.45);     /* 下缘折射线 */
transform: perspective(1500px) rotateX(var(--rx,0deg)) rotateY(var(--ry,0deg));
transition: transform 420ms var(--ease-out);
```

- **边框冷光**：`::before` 铺满，`padding: 1px`，一团 260px 白色径向渐变（位置 `--mx/--my`），双层 mask 只留 1px 的边。
- **表面柔光 + 颗粒**：`::after`，一层 340×280 白色径向渐变（位置 `--lx/--ly`）+ 一张 140×140 `feTurbulence`（SVG 内 `opacity=0.05`）。
- **玻璃里的光**（这是"液态"的主件）：`.sm-sheen` 一层 + 它的 `::before`/`::after`，三团白光在 32s / 46s / 58s 里各走各的，速度不同才像液体里的折射。
- **倾斜**：`--ry` ±1.5°、`--rx` ±1.05°，指针在板上跟手，离开 420ms 回位。倾斜只给大玻璃，**不给文字块、列表、按钮**。
- **弯月面**：所有液面（`.sm-bar i`、`.sm-form-tube u`、`.sm-scale-track i`）右端有一道 2px 白色细边，这是"液"的人证。
- **板子底下的一滩光**（`.sm-hero-side::before`）：一团模糊的浅蓝，16s 呼吸一次。玻璃"浮起来"靠的是它，不是靠加深底色。

关键约束：

- `--mx/--my`、`--lx/--ly`、`--rx/--ry` **只能由指针事件直接写 style 变量**，不许进 React state；统一走 `components/useGlass.ts`，触屏与 reduce-motion 不启用。
- 玻璃叠玻璃禁止：一屏**只有一块大玻璃**（交题板 / 追问卡），里面的小玻璃砖（输入格、选项、按钮、键帽）是"嵌进去的"，不是浮上去的。
- `backdrop-filter` 只允许出现在：`.sm-sheet`、`.sm-probe`、`.sm-top`、`.sm-brief`（滚动吸附时）。
- `saturate()` 不超过 170%：再高整块板子会发紫。

## 14.5 字体

```css
--sans: -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB",
        "Microsoft YaHei", system-ui, sans-serif;
```

全站一套无衬线，不引外部字体（本机直连外网不通，`next/font/google` 会卡死构建）。

"高级感"来自**字重、字距、字号三者的对照**，不来自换字体：

| `--fs-display` | `clamp(38px,4.8vw,68px)` | 首页字标（600，`-.044em`，行高 `1.02`） |
| `--fs-h1` | `clamp(27px,3.1vw,40px)` | 状态页主结论 |
| `--fs-h2` | `clamp(19px,2vw,25px)` | 卡点一句话 |
| `--fs-q` | `clamp(19px,1.9vw,23px)` | 追问句（500） |
| `--fs-lead` | `17.5px` | 导语 |
| `--fs-body` | `15.5px` | 正文 |
| `--fs-p` | `14.5px` | 次级正文 |
| `--fs-small` | `13px` | 注脚、按钮 |
| `--fs-meta` | `12px` | 元信息 |
| 小标签 | `10.5–11px` + `.16–.22em` 字距 | 段落标签、字段名、序号 |

全站 `font-variant-numeric: tabular-nums`；标题里要强调的词用 `.sm-hl`（一笔浅蓝液体高光），**不用渐变字**。

## 14.6 栅格与流动

- 版心 `--measure: 1160px`，左右 padding 36px；正文列 `--measure-read: 33em`
- 首页主区：`1fr + 424px`，间距 84px；**交题板比字标低 32px**（错位，不要对齐得像模板）；≤1080px 变单列，板子限宽 540px
- 追问页：左轨 218px ＋ 56px ＋ 舞台（`max-width: 660px`）；≤1080px 左轨变横向一条
- 间距：`--s1 4 / --s2 8 / --s3 14 / --s4 20 / --s5 28 / --s6 40 / --s7 56 / --s8 80 / --s9 112`
- 圆角只有 `10 / 14 / 22 / 999` 四档；**文字块本身不要圆角**
- 页面是**一整条流**，只有五种段落形态，不要发明第六种：

| 形态 | 类名 | 长什么样 |
|---|---|---|
| 字标 | `.sm-display` + `.sm-display-2` | 两行、一大一小、左对齐 |
| 小标签 + 序号 | `.sm-label em` | `01` 序号 + 10.5px 字 + 一条 18px 液面 |
| 一句话 | `.sm-statement` | 21–29px，**每段的层级就靠它** |
| 液态轨道 | `.sm-track` / `.sm-step` | 4 段 2px 液面拼成一条管道，上面一趟 7s 的流光滑过；悬停哪段就填哪段，珠子鼓一下 |
| 索引 | `.sm-index` | `字段名 ···· 它回答什么`，虚线引线，悬停引线变量、右端推 2px |
| 悬挂标签 | `.sm-note-item` | 左 7.5em 标签 + 右正文，标签前一颗玻璃珠（悬停变蓝） |
| 引文 | `.sm-quote` | 左 2px 蓝条 + 26–38px 大字，没有上下线 |

段落之间只用留白（80–112px）与一个 `.sm-label`，**不画分割线、不铺色带、不摆卡片**。段落入场由 `Reveal` 控制：进入视口的那一段上浮 12px + 淡入 520ms，子项按 70ms 错位，**读过的不再动**。

## 14.7 树突：唯一的数据可视化

树突 = 走过的路。**用节点数画，不用像素画。**

- 首页四格：题目 / 答案 / 过程 / 卡点。填了哪格亮哪格；光标停在某个字段，那一格也跟着亮。
- 追问页：每答一轮加一颗玻璃珠（`第 n 问` + 你原话的摘要）；指针停在某一行问答上，左轨对应的珠子亮起来；出卡时末端变成"卡点"节点。
- 说"不知道"的那一轮，枝干**向左让一步**——路径退回一级。

几何由序号算出，没有随机数（`Dendrite.tsx`，`step` 默认 58 / 追问页 46，脊线 `x=24`）。

| 状态 | 线 | 珠 |
|---|---|---|
| `done` | `--azure-line` | 实心蓝珠 |
| `active` | `--azure` 1.5px | 白珠 + 蓝边 + 3.2s 呼吸圈 + 6px 辉光 |
| `todo` | `--line-2` 虚线 | 半透明白珠 |
| `stuck` | `--azure-ink` 1.5px | 深蓝珠 + 三道短须 |

硬约束：

1. 节点数只能来自真实数据（`history.length` / 草稿字段），**不许预先画满**
2. 树突是 `<svg aria-hidden>` + 一份 HTML 文字标签（`ol.sm-d-labels`），读屏读到的是句子
3. `data-hot` 只是联动提示，不改变状态

## 14.9 能力构成表：**当前不上线**

主题"智商核心构成能力"唯一合法的界面形态，是「**这道题需要什么**」＋「**你的证据**」，而不是「你有什么」的分数。

三态（等数据到位再启用）：

| 状态 | 标记 | 含义 |
|---|---|---|
| 有证据 | 实心蓝珠 | 这一步你写对了，证据完整 |
| 缺一步 | 空心蓝珠 | 有动作缺失，能指出缺哪一步 |
| 未涉及 | 虚框珠 | 这题走不到这一步，不给结论 |

**现状**：后端 `CardOut` 只给 `layer / node_id / label`，不给节点全集，前端**没有**这张表。不许用假数据填，宁可空着。

1. 不产出分数、百分位、雷达图、等级
2. 三态只能由节点数据驱动，前端不得硬编码
3. 标题用「这道题需要什么」，不用「你的能力」

## 14.10 术语分层（对 §2.7 的落地）

| 层 | 默认可见 | 内容 |
|---|---|---|
| 第一层（人话） | ✅ | "先确认前提，再动手" |
| 第二层（术语） | ❌ 悬停或展开 | "inhibitory control · 在动作启动前抑制它" |

界面任何位置不得直接把"工作记忆""抑制控制"当标签摆出来。第二层必须同时给出**人话 + 英文术语 + 一句解释**。

## 14.11 动效

**只有两种动效**：跟手的（光、倾斜）和交代变化的（液面、键帽、错位入场）。状态变化 140–280ms，`ease-out`，没有回弹。

| 位置 | 做什么 | 参数 |
|---|---|---|
| 换屏 | 上浮 8px + 淡入 | 280ms |
| 换一问 | 追问卡接上（上浮 8px + 淡入） | 280ms |
| 段落入场 | 整段上浮 12px + 淡入；子项各错 70ms | 520ms |
| 玻璃里的光 | 三团白光各自漂移（32 / 46 / 58s） | 无限交替 |
| 整页游光 | 一团淡蓝光绕一圈 | 120s 线性 |
| 板下光滩 | 呼吸（缩放 + 透明度） | 16s 交替 |
| 轨道流光 | 一趟扫过管道（管道内裁切） | 7s 循环 |
| 标签圆点 | 呼吸 | 4.6s 循环 |
| 指针进玻璃 | 边框冷光 + 表面柔光跟位 | 跟随实时 |
| 指针进玻璃 | 面板倾 ±1.5° / ±1.05°，离开回位 | 跟随实时 / 回位 420ms |
| 输入聚焦 | 整格亮 + 3px 蓝晕 + 底部 1px 液线从左画出 | 300ms 画出 |
| 线索液面 | 宽度走位 + 一次亮度抬升 | 560ms / 460ms |
| 轨道悬停 | 该段液面从 0 填到 100% | 260ms |
| 索引悬停 | 虚线变亮 + 右端推 2px | 200ms / 140ms |
| 选项悬停 | 抬 1px + 底色亮一档 + 左条 2px 长出 + 键帽变蓝 | 140ms |
| 选项按下 | 压回 1px + 内阴影 | 140ms |
| 选项入场 | 上浮 6px + 淡入，每项错 40ms（最多 4 项） | 280ms |
| 对话行入场 | 上浮 6px + 淡入，每行错 60ms | 280ms |
| 按钮 | 悬停时里面那团光跟着指针；按下压 1px + 内阴影；箭头右移 3px | 140–200ms |
| 链接 | 悬停时 1px 下划线从左画出 | 300ms |
| 当前节点 | 呼吸圈 | 3.2s 循环 |
| 顶部液面 | 宽度随滚动 | 90ms |

**禁止**：水珠、扫光条、文字块位移/缩放、背景视差、文字逐字入场、超过 400ms 的装饰性动画、超过三层的光。

**允许但仅限"键"**（选项、按钮、键帽）：1px 的抬升/压回。这是物理反馈，不是装饰。

`prefers-reduced-motion: reduce` → 全部动画降到 0.01ms，倾斜与柔光都不跟手，信息不丢。

## 14.12 无障碍与性能

- 正文对比度：`--ink` on `#E0EAF5` ≈ 14:1；`--ink-3` 标签 ≈ 5.2:1；蓝底白字按钮 ≥ 4.5:1
- **整页禁止选中**（`user-select: none`），`input / textarea / [contenteditable]` 显式恢复 `text`
- 状态不只靠颜色：选中同时有左条 + 勾；当前节点同时有呼吸圈 + 文案
- 焦点环：`2px solid var(--azure-line)`，offset 3px
- 键盘：`1–4` 作答，`H` 看"为什么问这个"，Tab 可达所有控件
- 触屏：不接指针相关效果；选项 ≥ 44px 高；题面不吸附
- 性能预算：`backdrop-filter` 最多 4 处；玻璃里三层光只动 `transform`；颗粒是 SVG 底图，不用 canvas

## 14.13 反模式（出现即打回）

1. 深色玻璃 / 霓虹描边 / 紫粉渐变
2. **把底色压深**（比 `#D3E4F9` 更深）：整页发闷，玻璃反而看不出来
3. **色带分区、分栏细线、卡片阵列**——把一条流切碎成格子，是最容易犯的错
4. 按下水珠、按钮扫光条、文字块悬停位移/缩放
5. 背景跟随指针做视差
6. 文字逐字入场、列表依次淡入、超过 400ms 的装饰性动画
7. 玻璃叠玻璃、卡片里再套卡片
8. 光斑超过三团，或光斑盖住正文
9. 对**文字**做模糊、发光、渐变填充
10. 装饰性英文小标题（`TRACE` `INSIGHT` 这类）
11. 对偶金句、三个连续的"不是 X"
12. 给能力打分数或排名
13. 追问页看不见题面、或回首页要点两次
14. 11px 小字用 `--azure`（对比度不够，必须 `--azure-ink`）
15. 倾斜超过 1.5°，或给文字块加倾斜（会晕）

## 14.14 落地顺序

1. `tokens.css`：近白底、琉璃色、玻璃参数、字阶、间距、动效曲线（旧变量名保留为别名）
