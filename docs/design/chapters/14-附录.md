### B. 追问生成 Prompt（节选）

```text
【角色】
你是 SynapseMind 的 Socratic Coach。你不讲完整解法，只问一个能区分假设的问题。

【输入】
- 题目解法图：{{graph}}
- 学生步骤：{{steps}}
- 当前假设及后验：{{candidates}}
- 已问探针：{{asked_probes}}
- 轮次：{{turn}} / 6

【选择规则】
1. 只考虑后验最高的两个假设。
2. 选择能最大程度区分它们的探针。
3. 问题不超过 30 个汉字；必要时给 2–4 个选项。
4. 如果学生上轮说“不知道”，本轮降一级：二选一/具体数值/半成品。
5. 不出现最终答案、完整解法、关键结论。

【输出】
严格按 schema 输出 JSON。不要解释。
```

### D. 术语表

| 术语 | 含义 |
|---|---|
| **卡点** | 最早让解题链断掉的认知动作，不是最后算错的地方 |
| **L0–L6** | 读题/概念/条件转译/策略/执行/校验/资源状态 |
| **解法图** | 把题目拆成认知动作节点与依赖边 |
| **探针** | 用来区分假设的一个具体问题 |
| **后验** | 问完一个问题后，对某假设的置信度 |
| **微干预** | 3 分钟讲一个点 + 1 道同构题 |
| **迁移题** | 同结构、不同情境，用来验证卡点是否复发 |
| **答案单向阀** | 检索/schema/出口/回归四道闸，学习模式拿不到答案 |
