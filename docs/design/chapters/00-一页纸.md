## 0. 一页纸

> **不是讲这道题，是找到你卡住的那一步。**

### 0.1 用户带什么来

三种入口，同一个动作：

| 入口 | 用户提供 | 系统第一句话 |
|---|---|---|
| **我不会** | 题目文本/拍照，最多加一句“我读到哪就懵了” | “先不做整题。只看这一步，你能判断吗？” |
| **我做错了** | 题目 + 自己的答案/过程 + 正确答案（可选） | “先不看正确答案。你写到这一步时，心里是怎么想的？” |
| **答案对但没底** | 题目 + 答案 + “我是猜的/我不确定” | “答案先放一边。你能用自己的话解释这一步为什么成立吗？” |

### 0.2 系统做什么

不是直接给解答，而是用 **2–6 轮追问**，把“我不会”拆到一个可命名的卡点：

1. **拆题**：把题目拆成解法图（读题、概念、条件转译、策略、执行、校验）。
2. **对齐**：把用户的答案/步骤贴到解法图上，找第一处偏离。
3. **追问**：一次只问一个可回答的问题，用具体例子、反例、二选一，逼出真实理解。
4. **定位**：输出一张“卡点卡”——卡在哪一层、证据是什么、排除了什么、置信度多少。
5. **微干预**：3 分钟讲清一个点，配 1 道同构题 + 1 道迁移题。
6. **验证**：24 小时/7 天后用一道新题复测，确认不是“听懂了”。

### 0.3 一个真实片段

题目：`f(x)=ln x - a x`，`a∈R`，若 `f(x)≤0` 对任意 `x>0` 恒成立，求 `a` 的取值范围。

学生答案：`f'(x)=1/x-a`，令 `f'(x)=0` 得 `x=1/a`，最大值 `ln(1/a)-1≤0`，所以 `a≥1/e`。**答案对，过程漏了 `a≤0` 的讨论。**

系统没有说“你漏了 a≤0”，而是问：

> “先不急着看答案。你说‘令 f'(x)=0 得 x=1/a’，这一步用了除法。请只回答：当 `a=0` 时，`f'(x)` 是什么？在 `x>0` 上有零点吗？”

学生：“`1/x`，没有零点。”

> “那 `a=0` 时，`f(x)=ln x` 在 `x>0` 上会不会超过 0？”

学生：“会，`x>1` 就大于 0。”

> “所以 `a=0` 不符合。再看 `a=-1`：`f'(x)=1/x+1`，有零点吗？`f(x)` 在 `x>0` 上单调怎样？”

学生：“没有零点，一直增；x 很大时 `ln x + x` 也很大，肯定超过 0。”

> “很好。现在回到你的第一步：‘令 `f'(x)=0` 得 `x=1/a`’，它要求 `a` 满足什么？”

学生：“`a>0`。a<0 时 1/a 是负的，不在 x>0；a=0 也不行。所以只有 a>0 时这个驻点才在定义域里。”

> “对。你原来的解答没有检查这个前提。那你觉得，这次卡住的是求导、解不等式，还是‘用驻点前先确认参数范围’？”

学生：“最后一个。”

**卡点卡**：

| 项 | 内容 |
|---|---|
| 卡点 | L2 条件转译 / 参数分类讨论：使用驻点前，未确认 `a>0` 使 `x=1/a` 存在且落在 `x>0` |
| 证据 | 在 `a=0`、`a=-1` 时仍沿用 `x=1/a`；没有先判断驻点是否存在、是否为最大值 |
| 排除 | 求导正确；不等式求解正确；最终答案正确 |
| 置信度 | 0.86 |
| 下一练 | 用“存在性三步检查”重写开头；再做一道同构题（含参数分类） |
| 验证 | 24 小时后，新题中能否先写“驻点存在的条件”，再求导 |

### 0.4 我们不是什么

| 不是 | 为什么 |
|---|---|
| **题库/搜题** | 搜题给答案，我们给“你卡在哪”；答案在诊断完成前是锁住的 |
| **AI 家教** | 家教讲整道题，我们只追问一个点，讲 3 分钟就停 |
| **智商测试** | 不输出 IQ、百分位、等级；七维能力只在后台做“探针镜头” |
| **完整课程** | MVP 只做高中数学“函数与导数”，不承诺覆盖所有学科 |
| **提分承诺** | 只承诺“更准确地找到下一个该练的点”，不承诺分数 |

### 0.5 一句话价值

**把“我不会”从一句情绪，变成一个可命名、可验证、可训练的卡点。**

### 0.6 核心指标

| 指标 | MVP 目标 | 说明 |
|---|---|---|
| 诊断与双教师一致率 | ≥75% | 同一段对话，两位老师独立标注卡点，系统取一致 |
| 用户“说中了” | ≥70% | 诊断卡下方 1–5 分，“这个判断像不像你” |
| 平均追问轮数 | 4–6 轮 | 超过 6 轮必须给阶段性结论 |
| 首条有效追问延迟 | <8 秒 | 含 OCR/解析/检索 |
| 答案泄漏率 | 0 | 学习模式下，输出中不出现最终答案/完整解法 |
| 24 小时迁移 | ≥60% | 新题中不再犯同一卡点 |
| 单次成本 | ≤¥0.8 | 含 LLM、OCR、向量检索 |
