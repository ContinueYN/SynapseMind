# SynapseMind 突触智学

> 单题诊断：把“我不会”定位到一个可验证的卡点。

学生提交题目与作答过程。系统不评分、不排名，也不直接给出完整解答；它以 2–6 轮追问，定位解题链上最早失效的认知动作，并输出一张卡点卡：层位、证据、被排除的竞争假设、置信度、下一步训练。

模型的职责是生成候选问题与措辞；状态推进、证据门禁和停止条件由代码控制。

## 三种入口

| 入口 | 学生提供 | 系统首先确认 |
|---|---|---|
| 完全不会 | 题目，最多加一句“读到哪里懵了” | 题目中的哪个条件或符号无法转译 |
| 做错了 | 题目、自己的过程，可选正确答案 | 过程里哪一步开始失去依据 |
| 答案对但没底 | 题目、答案、自述“不确定” | 结论是否建立在未经检验的前提上 |

## 诊断流程

1. **拆题**：把题目拆成解法图。节点是七类认知动作：`READ`、`CONCEPT`、`CONDITION`、`STRATEGY`、`TRANSFORM`、`COMPUTE`、`CHECK`。
2. **对齐**：把学生步骤映射到图节点，标出 `ok`、`partial`、`missing` 或 `wrong`。
3. **定位断点**：沿依赖边向前走，找到第一个失效、且其前置节点均成立的节点。后续连带错误不计为根因。
4. **追问**：在 2–3 个候选假设之间选择区分度最高的探针，一次只问一个问题。
5. **收束**：后验达到 0.80 且领先第二名 0.25，输出卡点卡；否则最多 6 轮，按低置信收束。

## 一个例子

题目：`f(x)=ln x - a x`，`a∈R`；若 `f(x)≤0` 对任意 `x>0` 恒成立，求 `a` 的取值范围。

学生过程：求导，令 `f'(x)=0` 得 `x=1/a`，最大值 `ln(1/a)-1≤0`，所以 `a≥1/e`。答案正确，过程漏掉了 `a≤0` 的讨论。

系统没有指出“你漏了 a≤0”，而是从除法这一步切入：

> 你写“令 `f'(x)=0` 得 `x=1/a`”。当 `a=0` 时，`f'(x)` 是什么？在 `x>0` 上有零点吗？

学生回答后，系统继续用 `a=0` 与 `a=-1` 两个反例，让学生自己确认：使用驻点前，必须先保证 `a>0` 且 `1/a` 落在定义域内。

| 卡点卡 | 内容 |
|---|---|
| 卡点 | L2 条件转译：使用驻点前，未确认 `a>0` 使 `x=1/a` 存在 |
| 证据 | 在 `a=0`、`a=-1` 时仍沿用 `x=1/a`；未检查驻点存在性与最大值条件 |
| 排除 | 求导正确；不等式求解正确；最终答案正确 |
| 置信度 | 0.86 |
| 下一步 | 用“存在性三步检查”重写开头；完成一道含参数分类的同构题 |
| 验证 | 24 小时后，在新题中先写驻点存在条件，再求导 |

## 范围与边界

| 项 | 当前范围 |
|---|---|
| 学科 | 数学（函数与导数）、物理（力学）、语文（结构提示） |
| 输入 | 文本；拍照与 OCR 尚未接入 |
| 轮次 | 2–6 轮，一次一问 |
| 输出 | 数学/物理：卡点卡；语文：结构提示 |
| 不做 | 分数、排名、能力等级、完整解答、提分承诺 |
| 未接入 | PostgreSQL、Redis、RAG、鉴权、多租户 |

语文没有客观真值，系统只对齐步骤结构并给出提示，不追问、不判定卡点。物理验证依赖结构化量纲与数值回代；纯文本步骤返回 `unknown`。

## 已验证

| 项 | 结果 |
|---|---|
| 100 道未见数学题的结构化合图 | 100/100 通过 schema 与结构规则；101 次模型调用、1 次重试；p50 4.17s / p95 4.83s |
| 20 道未见题的首问延迟 | p50 4.2s / p95 4.7s（含现场建图、对齐与探针规划，预算 8s） |
| 10 条金标准回放 | 10/10 通过，平均 2.40 轮 |
| 单步验证 | 数学只返回 `fail` 或 `unknown`；物理按量纲与数值回代返回 `pass` / `fail` / `unknown` |

上述数字用于验证工程链路与契约，不代表诊断准确率。卡点是否指对，仍需教师标注与真实学生作答校准。
