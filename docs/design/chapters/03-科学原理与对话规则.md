## 3. 科学原理如何变成对话规则

> 这一章不写“脑科学综述”，只写“哪条原理，落到哪句追问”。
> 每条原理都必须能回答：**如果它成立，系统下一句话应该怎么变？**

### 3.1 六条原理 → 六条对话规则

| 原理 | 一句话解释 | 对话规则 | 反例（不要这样做） |
|---|---|---|---|
| **先验知识/图式** | 新知识必须挂在已有结构上，否则记不住 | 先问“你已经知道什么”，用他的原话做锚点 | 一上来讲完整解法 |
| **预测误差** | 预期被打破时，注意力和编码最强 | 先让他预测下一步/结果，再给反例 | 直接说“正确答案是……” |
| **认知负荷** | 工作记忆一次只能处理少量新元素 | 一次只问一个点；长题先分段；把条件外显 | 一条消息问三个“为什么” |
| **提取练习** | 从记忆中取出来，比再读一遍更能巩固 | 让他复述/默写/解释，而不是“看懂了吗” | 把答案放在屏幕上让他点头 |
| **自我解释** | 能说出“为什么”才算真的接上 | 追问“这一步为什么成立”“如果改成……还成立吗” | 只问“对不对” |
| **元认知校准** | 以为自己会，和真的会，常常不一致 | 每题记信心；诊断后让他评“像不像你” | 用“懂了吗”代替校准 |

### 3.2 七个能力维度：只做“探针镜头”，不做分数

我们不输出 IQ，也不输出“工作记忆 72 分”。七维只用于**选择下一个问题**：

| 维度 | 在单题里的表现 | 探针示例 | 不能据此下结论 |
|---|---|---|---|
| **V 言语理解** | 读不懂“任意/存在”“恒成立”“至少” | “把‘对任意 x>0 恒成立’改成你自己的话，怎么说？” | 不能说他“语文差” |
| **Gf 流体推理** | 遇到新定义/新结构，抽不出规则 | “如果题目把 `ln x` 换成 `e^x`，哪一步会变？” | 不能说他“智商低” |
| **Gv 视觉空间** | 不画图，或画图后看不出关系 | “你能把 f(x) 和 f'(x) 的草图分开画吗？” | 不能说他“没有空间感” |
| **WM 工作记忆** | 多条件同时处理时丢条件 | “先只做第一步，把 a>0 写在纸上，再往下。” | 不能说他“记性差” |
| **Gs 加工速度** | 会做但慢，考试做不完 | “不计时，先做对；慢在哪一步？” | 不能说他“笨” |
| **LTS 长时存取** | 公式/定理想不起来，看到就懂 | “遮住公式，写出 `(ln x)'` 和 `(x^a)'`。” | 不能说他“基础差” |
| **M 元认知** | 信心高但做错，或不知道哪个点不会 | “这题你觉得自己能对几成？为什么？” | 不能说他“态度不好” |

**使用原则**：

1. 七维是**假设生成器**，不是诊断结论；
2. 每个维度至少要有 2 个行为信号，才允许进入候选；
3. 对外只说“这次卡在哪”，不说“你哪项能力低”；
4. 任何维度都不能用于分班、排名、贴标签。

### 3.3 认知负荷：把“大问题”切成“能回答的小问题”

一道高中导数题，对新手可能是 7–9 个元素同时在线：参数、定义域、导数、驻点、单调性、极值、端点、不等式。工作记忆装不下，就会“看起来会，一做就乱”。

系统的做法：

- **分段**：先只判断“a≤0 时有没有最大值”，不要求解完；
- **外显**：让用户把“a>0”写在纸上/输入框里，减少内存负担；
- **单点**：一轮只处理一个条件，不同时问“定义域和单调性”；
- **降级**：用户说“不知道”，给二选一或具体数值，而不是重复原问题。

### 3.4 预测误差：让“哦”发生在对话里

直接告诉学生“你漏了 a≤0”，他只会点头。更有效的是让他先预测，再看到预测被打破：

> “你觉得 a=-1 时，f(x) 会不会超过 0？”
>
> 学生：“应该不会吧，ln x 增长很慢。”
>
> “那你代入 x=10 试试：ln 10 + 10 是多少？”
>
> 学生：“12.3……哦，会超过。”

这个“哦”就是预测误差。它比十句“注意分类讨论”更有用。

### 3.5 提取练习与自我解释：不问“懂了吗”

| 坏问题 | 为什么坏 | 好问题 |
|---|---|---|
| “懂了吗？” | 社交压力下，学生几乎都说懂 | “遮住上面，用自己的话复述这一步。” |
| “哪里不会？” | 太抽象，学生真的不知道 | “你是卡在‘不知道用哪个公式’，还是‘知道公式但不会代’？” |
| “为什么？” | 对不会的学生，开放式问题像审问 | “如果我只改一个条件，你觉得哪一步会变？” |
| “你再想想。” | 没有提供任何支架 | “给你一个提示：先看 a=0。现在能判断吗？” |

### 3.6 巩固与迁移：诊断不是终点

一次对话只能解决“看见卡点”，不能保证“长期掌握”。所以系统在诊断卡后接两个动作：

1. **24 小时迁移**：一道同结构、不同情境的题，只测“卡点是否复发”；
2. **7 天变式**：把参数、函数类型或问法换掉，测“是否只会原题”。

这不是“记忆曲线”的装饰，而是把“听懂”与“能做”分开。

### 3.7 神经可塑性的正确用法

可塑性不是“练得越多越聪明”，而是：

> **有针对性的、有反馈的、有难度的重复，才会改变连接。**

对应产品约束：

- **针对性**：只练被诊断出的那一个点，不整套刷题；
- **有反馈**：每道微练立刻告诉“这一步对不对，为什么”；
- **有难度**：在“跳一跳够得着”的区间，不完全不会，也不一眼就会；
- **有间隔**：24 小时/7 天复测，而不是当晚刷十遍；
- **有情绪安全**：不羞辱、不贴标签；焦虑时先降难度。

### 3.8 伦理红线

| 红线 | 具体做法 |
|---|---|
| 不测智商 | 不输出 IQ、百分位、等级、 “你的工作记忆相当于……” |
| 不下医学诊断 | 不出现 ADHD、抑郁、学习障碍、感统失调等判断 |
| 不排名 | 不显示“你超过了 83% 的同龄人” |
| 不承诺分数 | 不说“练完这套提 20 分” |
| 不制造焦虑 | 不用“你现在已经落后”之类的话术 |
| 未成年人保护 | 默认最小化收集；照片不留存原图；家长视图只看趋势，不看原始作答 |

### 3.9 一句话总结

**脑科学不是用来讲故事的，是用来决定“下一句话问什么、问多难、什么时候停”的。**
