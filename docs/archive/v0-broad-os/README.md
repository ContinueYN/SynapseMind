# SynapseMind 突触智学

> 让每一次努力，落在正确的突触上。

**一个基于脑可塑性与智商核心构成能力的 AI 学习引导系统。**
不回答"你有多聪明"，只回答"这一次你卡在哪一步、下一步练什么"。

---

## 这是什么

一个"学习方式的操作系统"：用 12 分钟轻诊断 + 一道题的五段解剖 + 一张带证据的处方卡，把"刷题—对答案—再刷题"改造成"诊断—归因—处方—验证"的闭环。

**不是**智商测试，**不是** AI 家教，**不是**题库。

## 三个关键洞察

1. **错题不是证据，错题的发生过程才是证据。** 同一个"×"，可能是知识缺口、工作记忆负荷、加工速度、言语理解、长时提取或元认知偏差。
2. **能力需求是"题 × 学生"的联合函数。** 同一道题，对三个学生是三种病因、三种处方。
3. **AI 不产生分数，只产生偏移。** 规则/IRT 产生假设，LLM 只做解释、检索与措辞。

## 五个可演示亮点

| # | 亮点 | 一句话 |
|---|---|---|
| 1 | 能力需求向量 | 把"题目难度"升级成"题 × 学生"的七维向量 |
| 2 | 同一道错题，三种病因 | 90 秒内看到三种归因与三种处方 |
| 3 | 规则定骨架，LLM 只做措辞 | 结论稳定、可复现、可降级 |
| 4 | 答案单向阀 | 索引/检索/生成/出口四道闸，学习模式拿不到答案 |
| 5 | 证据卡 +「我不同意」 | 每个结论有证据、置信度、反证条件 |

## MVP 边界

| 项 | 决策 |
|---|---|
| 学科 | 高中数学"函数与导数"，12 知识点，300 题 |
| 诊断 | 12 分钟核心 24 题 + 8 分钟可选扩展；第 6 题给首张卡 |
| 团队/周期 | 3–5 人 / 10 周 |
| 架构 | 4 个部署单元（gateway/core/content/ai），按 9 个服务设计 |
| AI | 3–4 个 Agent 上线；7 Agent + 8 MCP 工具为目标架构 |
| 验证 | 1,000 注册 / 300 WAU / 40–60 人封闭 beta |
| 生死线 | 诊断完成率 ≥55%、4 周处方执行率 ≥35%、¥9.9 体验转化 ≥5% |

## 诚实说明

这是一个**项目设计方案**，不是已上线产品。文中的完成率、留存、成本、LTV 均为**设计目标或估算**，已标注"目标/假设"。当前没有真实用户数据、没有 300 题标注、没有疗效证据。第 9.7 节列出了全部缺口与补法。

**这个项目最难的不是 AI，是把 300 道题标得连两个老师都同意，以及让一个 17 岁的学生在第 6 题后相信"这个系统懂我"。**
