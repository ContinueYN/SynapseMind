## 阅读提示

这不是一份"功能清单"，而是一份**带取舍的设计文档**。每一章都尽量回答三个问题：

1. **为什么做这个决定？**
2. **代价是什么？**
3. **什么情况下这个决定会错？**

文中所有完成率、留存、成本、LTV 均为**设计目标或估算**，不是已上线数据。第 9.7 节列出了当前方案的全部缺口。请带着"这是否可行"的问题读，而不是"这是否酷"。
