# ADR-0003: 生成图的证据权重校准

- **状态**：accepted
- **日期**：2026-10-30
- **决策者**：产品与开发
- **相关**：[`graph_structure.py`](../../apps/api/src/synapse/domain/problem/graph_structure.py)、[`graph.py`](../../apps/api/src/synapse/infrastructure/llm/graph.py)

## 1. 背景

生成图接入 ALIGN/PROBE 后，未见题的出卡率只有 7/20。链路本身正常：建会话 20/20，卡点节点 7/7 都属于该图。问题在证据强度：85 个探针的 510 条权重中，max|w|=0.60，|w|≥0.8 的为 0。卡点门槛仍是“后验 ≥0.80 且领先 ≥0.25”，6 轮内无法形成差距，最后按低置信收束。

由此产生一个需要显式决定的问题：模型给出的 log-odds 量级不可信时，代码是否应当替它定标？

## 2. 约束

| 约束 | 依据 |
|---|---|
| 不得通过降低 0.80/0.25 门槛提升出卡率 | 诊断结论必须使用同一套判定标准 |
| 同一张图内探针的相对强弱由模型判断，代码不重排 | 诊断层只做打分，不发明结构 |
| 人工标定的种子图权重不被生成图规则修改 | 种子题回归基线 |
| 任何机械修改必须可观测，不能静默 | 修复码必须进入结果 |
| `pass` 表示反例搜索未发现反例，不表示数学证明 | 验证器语义 |

## 3. 选项

| 选项 | 做法 | 不选的理由 |
|---|---|---|
| A. 下调未见题门槛 | 例如 0.65 + 0.15 | 同一个状态机出现两套诊断标准，M2 的种子题与 golden 不可比；也会掩盖证据本身太弱 |
| B. 只改 prompt | 要求模型写满 ±1、拉开选项差距 | 作为**第一选择**采用（`graph-v4`–`graph-v6`），但模型仍可能写成 0.4–0.6；只靠 prompt 没有兜底 |
| C. 逐探针归一化 | 每个探针各自放大到 max=0.90 | 会把「模型认为很弱的探针」抬到和决定性探针一样强，破坏探针之间的相对强弱 |
| D. 全图统一校准 | 全图最大 \|w\|<0.90 时，所有探针乘同一系数到 0.90 | **采用**：只改量级，不改符号与相对强弱；只放大不缩小 |

## 4. 决策

**采用 B + D。**

1. 生成 prompt 升到 `graph-v6`，要求每个探针至少有一个权重达到 ±0.8~1.0，同一假设在不同选项上的权重差 ≥1.0，整图覆盖 H_L1/H_L2/H_L4。
2. 图构建器在结构规则里调用 `review(..., calibrate_evidence=True)`：
   - 只对生成图生效（`require_evidence=True` 的路径），手写种子图不走；
   - 仅当全图峰值 `0 < max|w| < 0.90` 时，按 `0.90 / max|w|` 全图统一放大；
   - 四舍五入到 3 位小数，权重仍落在 −1~1；
   - 记录修复码 `evidence_calibrated`，不静默。
3. 校准**不改变**卡点门槛 0.80/0.25，也不把 `pass` 当成证明。

## 5. 后果

- 生成图的证据强度下限被抬到 0.90；探针之间「谁更强」仍由模型决定。
- 若模型已经写出 ≥0.90 的权重，代码不动它；若模型写出 0.95，也不下调。
- 校准只保证「答了会按相对方向更新后验」，不保证数学结论正确；后者仍由 claim + SymPy 反例负责。
- 手写种子图逐字节不变，10 条 golden 仍 10/10。

## 6. 验证

- 20 道未见题、真实 key、`aligned` 策略：建会话 20/20，出卡 **20/20（100%，上一轮 7/20）**，卡点节点 20/20 在图内；125 个探针、750 条权重，max|w|=0.90，|w|≥0.8 的 350 条；p50 6.4s / p95 9.3s。报告：`eval/reports/m2.5-s5-session.md`。
- 同一轮 `s5_verify`：`P_DERIV_003` 在 `graph-v6` 下第一次写 `(-∞,e]`，反例 `a=-24.46` 推翻负参数段；带反例重试一次仍保留，按设计丢弃 claim、保留图（`claim_dropped_refuted`）。claim 接受 0/20、推翻 1/20、其余 19 题无 claim。报告：`eval/reports/m2.5-s5-verification.md`。校准能修「证据太弱」，修不了「数学结论错」，两者不能混为一谈。
- 离线敏感性实验（不随仓库发布）：原图 4/20，全图放大到 0.90 后 20/20；逐探针归一化与全图校准都能过卡，选全图是为了保留相对强弱。
