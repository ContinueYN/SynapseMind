# Evaluation & Verification

> 这个目录只发布**评测协议与汇总证据**，不发布原始语料、逐题标注、生成图和内部复盘报告。
>
> 题目、学生作答、教师标注和逐题输出属于私有评测材料；把它们放进公开仓库既不利于保护数据，也容易把一次小样本运行误读成产品结论。

## 1. 评测栈

| 层 | 回答的问题 | 公开内容 | 私有内容 |
|---|---|---|---|
| **契约层** | 代码是否仍然遵守状态机、JSON Schema 和分层边界？ | `apps/api/tests/`、`apps/web/**/*.test.tsx`、`e2e/` | 无 |
| **能力层** | 结构化输出、验证器和多学科插件是否真的接通？ | `scripts/eval/` 中的评测入口与判定阈值 | 题集、逐题图、逐题 verdict |
| **校准层** | 诊断卡指出的卡点是否与教师判断一致？ | 协议、指标定义、汇总口径 | 双教师标注、学生原文、逐条复盘表 |

契约层除依赖私有 golden 的回归外，可在 fresh clone 上直接复现；能力层与校准层需要私有语料和模型 key，公开仓库只保留可审计的**方法与聚合结果**。

## 2. 汇总证据

以下数字来自 2026-10-31 的内部运行，口径固定、可追溯到对应脚本；它们证明的是工程链路与契约，不是学习效果。

| 维度 | 口径 | 结果 |
|---|---|---|
| 后端契约 | `pytest`（规则模式，无外部 key） | 本地全量 **359 passed**；公开 CI 收集 **337**、跳过 3 个依赖私有 golden 的用例，0 failed |
| 前端组件 | Vitest + jsdom | **39 passed / 6 files** |
| 浏览器接线 | Playwright + mock API（数学 fail/unknown、物理声明结果/容差、390/1280 布局） | **4/4 passed** |
| 规则基线 | 10 条 golden 回放，判定口径与 M2 §12.3 同源 | **10/10**，平均 **2.40 轮**（上限 6） |
| 结构化合图 | 100 道未见数学题，schema + 结构规则 + 证据完整性 | **100/100** 结构合法；101 次调用、1 次重试；p50 **4.17s** / p95 **4.83s** |
| 首问延迟 | 20 道未见题，只测 `SessionService.start()`（含现场建图、对齐、探针规划） | p50 **4.2s** / p95 **4.7s**，预算 **8s** |

延迟与合图数字是单机、固定 prompt 版本下的工程测量，不是 SLA；供应商 TTFT、重试题和并发都会改变尾延迟。

## 3. 指标定义

- **结构合法**：输出通过 `specs/solution-graph.schema.json`，且满足节点/探针/证据权重的结构规则；不等于数学结论正确。
- **首问延迟**：从服务端 `start()` 进入，到第一问可返回；不含 OCR、网络传输和浏览器渲染。
- **卡点一致率**：系统给出的卡点节点与双教师多数标注一致的比例；需要人工校准，不能用「出卡率」代替。
- **验证结论**：`pass` 只表示在给定网格与容差内未找到反例；`fail` 必须带可复算的反例；`unknown` 表示读不懂、缺数据或未启用验证。
- **泄漏**：模型输出中出现受保护答案片段或越界内容；由规则检查 + 人工抽样共同判定。

## 4. 怎么读这些数字

1. **先看样本量**。10 条 golden 与 20 道延迟题只够做回归门禁，不够支撑「诊断准确率」。
2. **区分接线与准确率**。出卡率、schema 通过率、插件覆盖率都是接线指标；卡点是否指对，必须看人工校准。
3. **不把 `pass` 当证明**。验证器是反例搜索；`unknown` 不是「通过」，`pass` 也不是「已证明」。
4. **不比较不同 prompt 版本的数字**。合图与延迟结论都绑定报告里的 prompt 版本和模型 id。

## 5. 复现边界

```text
公开：契约测试、评测脚本、指标定义、聚合结果
私有：题集、学生作答、教师标注、逐题图、逐题报告
```

`scripts/eval/` 里的入口保留完整判定逻辑；没有私有语料时，脚本会在读取数据阶段失败，而不是退化成另一套口径。这正是「公开方法、不公开材料」的边界。

## 6. 数据与伦理

- 不发布学生原文、账号标识或可回溯到个人的元数据；
- 公开汇总只保留样本量、版本、模型 id 和聚合分布；
- 评测材料的使用范围遵循项目的数据最小化原则；需要复核时在私有工作区运行，不把逐题内容贴回公开仓库。
